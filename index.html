mysim.out 파일을 여기에 끌어다 놓으세요

MyLogic 시뮬레이션 결과(.out)를 열어 진리표, 7-세그먼트 출력, 타이밍 파형을 확인합니다.
같은 폴더의 vhdl 파일도 함께 놓으면 진리표에서 입력 신호를 정확히 구분합니다.

출력 검증

검증 기준

진리표

전체 출력

칸을 누르면 해당 입력으로 이동합니다. 붉은색 칸은 표준 7-세그먼트와 다른 출력이고, 아래 글자가 틀린 세그먼트입니다.

타이밍 파형

파형을 누르면 그 시점으로 이동 · Ctrl+휠로 확대/축소 · 키보드 ← → Space Home

16자리 FND — 세그먼트를 누를 때마다 꺼짐 → 켜짐 → X(돈케어)

각 칸은 입력 W X Y Z(W가 최상위 비트) 한 가지에 대응합니다. 칸 오른쪽 위 X 버튼은 그 FND 전체를 돈케어로(다시 누르면 비움) 바꿉니다. FND 칸을 선택한 뒤 0–9, A–Z를 누르면 그 글자 모양으로 바뀝니다 (한글 입력 상태에서도 동작). X는 돈케어, Backspace/Delete는 지우기, ← →는 칸 이동입니다. 만든 모양은 이 브라우저에 자동 저장됩니다. 세그먼트는 Tab으로 옮겨 Space/Enter로 바꿀 수도 있습니다.

진리표 (W X Y Z → A~G)

카르노 맵

행은 W X, 열은 Y Z이며 그레이 코드 순서입니다. 칸 모서리의 작은 숫자는 입력값(0~15)이고, 노란 X는 돈케어입니다. 같은 색의 묶음과 식의 항이 서로 대응하며, 가장자리를 넘어 이어지는 묶음은 양쪽 끝에 열린 모양으로 그려집니다. 최적의 식이 여러 개면 목록에서 고를 수 있고, 고른 식만 색이 입혀집니다. 칸을 누르면 해당 입력이 FND와 진리표에서도 강조됩니다.
