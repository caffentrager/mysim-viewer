# MySim Viewer

MyLogic 시뮬레이션 결과 파일(`mysim.out`)을 브라우저에서 확인하는 뷰어입니다.
기존 VB6 프로그램(MySim Viewer2)을 웹으로 다시 만들었고, 설치나 OCX·VB 런타임이 필요 없습니다.

## 사용법

**온라인**: https://caffentrager.github.io/mysim-viewer/ 에서 바로 사용할 수 있습니다. (파일은 브라우저 안에서만 처리되고 서버로 전송되지 않습니다.)

**내 PC에서**:

1. `index.html`을 Chrome 또는 Edge에서 엽니다. (더블클릭)
2. `mysim.out` 파일을 **파일 열기** 버튼으로 고르거나 화면에 끌어다 놓습니다.

파일이 없으면 **데모** 버튼으로 둘러볼 수 있습니다.

## 샘플

[`samples/`](samples)에 바로 열어볼 수 있는 결과 파일이 있습니다.

| 파일 | 내용 |
|---|---|
| `fnd.out` | BCD → 7-세그먼트 디코더. 모두 정상 |
| `fnd-error.out` | 위와 같지만 8은 G가, 9는 B·C가 꺼져 있는 **오류 예제** (검증·디버깅 기능 확인용) |
| `fa.out` | 전가산기 |
| `adder2bit.out` | 2비트 가산기 |
| `xor3-parity.out` | 3입력 XOR 패리티 |

## 기능

- **출력 검증**: `다음 출력 확인`을 누를 때마다 다음 입력으로 넘어가며 7-세그먼트 출력을 표준 모양과 비교합니다.
  틀린 세그먼트는 `A B C D E F G` 글자와 점선으로 표시됩니다.
  - 인정하는 모양: 1(좌/우), 6·7·9(획 유무), A(대/소문자), C(대/소문자)
  - 검증 기준: BCD 0–9 / Hex 0–F / 끄기
  - 출력 극성: 공통 애노드처럼 0이 켜지는(Active Low) 회로는 `출력 극성`을 바꾸면 파일의 0을 켜짐으로 읽습니다. (진리표의 값은 파일 그대로)
- **신호 매핑**: 신호 이름이 A~G · W X Y Z가 아니면(예: `SEG0`~`SEG6`, `I3`~`I0`) `신호 매핑`에서 어느 신호가 무엇인지 직접 고릅니다. 같은 파일을 다시 읽어도 유지되고, 다른 파일을 열면 초기화됩니다.
- **전체 출력**: 모든 입력의 7-세그먼트를 한눈에 보고, 문제 세그먼트별 요약(`G 2건 · 입력 8, C`)을 제공합니다. 칸이 96개를 넘으면 일부만 그리고, 나머지에 불일치가 몇 개 있는지 알려 주며 `나머지 모두 보기`로 펼칩니다.
- **진리표**: 입력 열을 앞으로 모으고, 입력값을 10진수와 16진수로 함께 보여줍니다. 반복되는 행은 접을 수 있습니다.
- **타이밍 파형**: 신호별 파형과 버스 값을 보여주며 Ctrl+휠로 확대/축소합니다.
- **다시 읽기 / 변경 자동 감지**: 시뮬레이션을 다시 돌리면 결과가 자동으로 갱신됩니다. (Chrome/Edge)
- 라이트/다크 테마, 키보드 조작(`←` `→` `Space` `Home` `End`)

## 파일 형식

```
[MySim Result V3.5]
MAX_TIME 1000;
VECTOR <이름> W X Y Z;
WATCH A B C D E F G W X Y Z <이름>;
TABLE_ORDER A B C D E F G W X Y Z;
START
0 11111100000
10 01100000001
...
END
```

CP949(한글 Windows) 인코딩도 자동으로 읽습니다.

## 개발

빌드 과정이 없는 단일 파일(`index.html`)이며 외부 라이브러리를 쓰지 않습니다.
